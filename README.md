# Beespenser — Releases

Signed Windows installers for the Beespenser desktop application.

This repository contains **no source code**. It exists to host release
downloads and the update manifest the app reads.

## Download

Get the latest installer from the [Releases page](../../releases/latest).

Download `Beespenser_<version>_x64-setup.exe` and run it.

## Requirements

- Windows 10 or 11, 64-bit
- A Beespenser machine connected over USB

## Updates

Version 0.6.1 must be installed by hand, once. From that point the
application checks for updates on its own and offers them in-app — you
click once, it installs and restarts. Updates are refused while the
machine is running a job or probing.
